# 배선 규칙 전이: 사용한 모델, 전이 지수의 수식, 그렇게 만든 근거

> E4(`sctransfer/run_rule_transfer.py`, `sctransfer/run_rule_transfer_spatial.py`)의 방법을 논문 Methods에 옮길 수 있게 정리한 문서입니다. 결과는 [experimental_design.md](experimental_design.md) 4e~4i절에 있고, 확정 수치는 4i절입니다.
> `【확인 필요】`는 서지 정보를 원문으로 다시 확인해야 하는 곳입니다.

---

## 1. 질문을 모델 언어로 바꾸기

"선충의 배선 규칙이 초파리로 옮겨 가는가"를 검증하려면 먼저 **"배선 규칙"이 무엇인지 수식으로 정해야** 합니다. 요구 조건은 세 가지입니다.

1. **노드 대응이 필요 없어야 합니다.** 선충 뉴런과 초파리 뉴런은 1:1로 짝지을 수 없습니다. 그래서 "뉴런 A는 뉴런 B와 연결된다" 같은 규칙은 옮길 수 없고, "어떤 성질을 가진 쌍이 연결되기 쉽다" 같은 규칙만 옮길 수 있습니다.
2. **매개변수가 적고 해석할 수 있어야 합니다.** 그래야 한 종에서 맞춘 값을 다른 종에 그대로 적용할 수 있고, 무엇이 옮겨 갔는지 말할 수 있습니다.
3. **신경계 크기에 무관한 단위여야 합니다.** 선충 뇌는 수십 µm, 초파리 성체 뇌는 수백 µm입니다.

이 조건을 만족하는 표준 도구가 **생성 네트워크 모델(generative network model, GNM)**, 특히 "경제적" 생성 모델입니다(Vértes et al., 2012; Betzel et al., 2016; Akarca et al., 2021). 연결 하나하나를 비용과 가치의 균형으로 확률적으로 만드는 모델입니다.

다른 후보를 쓰지 않은 이유는 다음과 같습니다.

| 후보 | 쓰지 않은 이유 |
| --- | --- |
| 확률적 블록 모델(SBM) | 블록(세포 유형) 정의가 종마다 달라 블록 간 확률을 옮길 수 없음 |
| 잠재 공간 모델, 그래프 신경망 | 매개변수가 많고 해석이 어려워 "무엇이 옮겨 갔는지" 말하기 어려움 |
| 발달 생성 모델 (Richter & Schneidman, 2025) | 세포 유형·출생 시점 정보가 필요해 종 간 대응이 안 됨 |

## 2. 사용한 모델

### 2.1 성장 규칙

빈 그래프(n개 노드)에서 시작해 연결을 하나씩 더해 목표 연결 수 m에 도달할 때까지 키웁니다. 매 단계에서 아직 연결되지 않은 쌍 (i, j)를 다음 확률로 고릅니다.

```latex
P(i \sim j) \;\propto\; D_{ij}^{\,\eta} \;\cdot\; \left(M_{ij} + \varepsilon\right)^{\alpha} \;\cdot\; \big((k_i + 1)(k_j + 1)\big)^{\beta}
```

| 항 | 정의 | 무엇을 나타내나 | 근거 |
| --- | --- | --- | --- |
| D^η | 두 뉴런 사이 유클리드 거리를 표본 안 평균 거리로 나눈 값 | **배선 비용**. η < 0이면 먼 연결을 피함 | 배선 길이 절약 원리 (Bullmore & Sporns, 2012). 선충에서 뉴런 배치가 배선 길이 최소화로 설명됨 (Chen, Hall & Chklovskii, 2006) |
| (M + ε)^α | 이웃 겹침(matching index): 두 노드의 이웃 중 공유하는 비율 | **동질성(homophily)**. 이웃이 비슷한 노드끼리 연결 | 인간 거시 커넥톰에서 가장 잘 맞는 생성 규칙 (Betzel et al., 2016), 배양 뉴런에서도 확인 (Akarca et al., 2023 `【확인 필요: 저자】`) |
| ((k_i+1)(k_j+1))^β | 현재 차수의 곱 | **선호적 연결**. β > 0이면 이미 연결이 많은 노드에 더 붙어 허브가 생김 | 선호적 연결 모델 (Barabási & Albert, 1999), Betzel et al. (2016)의 차수 기반 규칙 |

세부 선택과 이유입니다.
- **곱의 형태**: 각 요인이 독립적으로 확률을 키우거나 줄이는, GNM의 표준 형태입니다(Betzel et al., 2016; Akarca et al., 2021).
- **거리 정규화**: D를 표본 안 평균 거리로 나눠서 η가 "신경계 자신의 크기 대비 먼 연결을 얼마나 피하는가"가 됩니다. 이렇게 해야 선충(µm 규모 신경환)과 초파리 η를 비교할 수 있습니다.
- **ε = 10⁻⁵와 k + 1**: 처음에는 모든 노드의 이웃 겹침과 차수가 0이라, 그대로 거듭제곱하면 확률이 0이나 무한대가 됩니다. 이를 막는 최소한의 보정입니다.
- **빈 그래프에서 시작**: Betzel et al. (2016)은 피험자 공통 연결을 씨앗으로 썼습니다. 종 간에는 공통 연결을 정의할 수 없어서 씨앗 없이 시작합니다.
- **이진·무방향 그래프**: 시냅스 수 같은 가중치는 종마다 척도가 달라 쓰지 않습니다. 정규화 통계 비교와 같은 원칙입니다.

α = β = η = 0이면 모든 쌍이 같은 확률이라 **같은 n, m의 ER 무작위 그래프**가 됩니다. 이것이 "규칙 없음"이고, 전이 지수의 0점입니다(4절).

### 2.2 대상 그래프

- 선충 뇌 8개체(Witvliet et al., 2021), 유충 좌우 반구(Winding et al., 2023), 성체 FlyWire 중심뇌 좌우 반구, 모두 12개 그래프입니다.
- 각 그래프에서 씨앗 하나 너비 우선 확장으로 **n = 150 뉴런** 표본을 뽑고, **밀도 4%**(m = 447 연결)로 맞춥니다. 규모 차이를 노드 수와 밀도에서 먼저 없애는 것으로, 4d절의 통계 비교와 같은 설정입니다.
- 위치(D)는 선충은 3D 세포체 아틀라스, 유충과 성체는 시냅스 중심점입니다(4h절).

### 2.3 적합도: energy

모델 그래프와 실제 그래프의 차이는 Betzel et al. (2016)의 energy로 잽니다.

```latex
E = \max\big(\,KS_{\text{degree}},\; KS_{\text{clustering}},\; KS_{\text{betweenness}},\; KS_{\text{edge length}}\,\big)
```

KS는 두 분포(노드별 차수, 노드별 클러스터링, 노드별 매개 중심성, 연결 길이) 사이의 Kolmogorov–Smirnov 통계량입니다. 거리 항이 없는 위상 모델에서는 연결 길이 항을 뺍니다.

- **KS를 쓰는 이유**: 값이 0~1이라 척도가 다른 통계를 한 기준에 놓을 수 있고, 평균만이 아니라 분포 모양 전체를 비교합니다.
- **최댓값을 쓰는 이유**: 모델이 네 성질을 모두 재현해야 낮은 energy가 나옵니다. 평균을 쓰면 한 성질을 아주 못 맞춰도 다른 성질로 메울 수 있습니다.
- energy 0은 완벽한 재현입니다. 같은 n, m의 ER 그래프는 대상에 따라 0.43~0.62이고, 대상 자신의 규칙은 0.24~0.41입니다(최종 실행).

### 2.4 맞추기

- **격자 탐색**: η는 −2.0~0을 0.25 간격으로, β는 0.5~2.0을 0.25 간격으로 봅니다. α는 앞선 모든 실행(α를 −1~3까지 열어 둔 것 포함)에서 0이 골라져 0으로 고정했습니다. ER 널 규칙 (0, 0, 0)은 항상 포함합니다.
- **표본 나누기**: 그래프마다 표본 16개를 맞추기 8개, 평가 8개로 나눕니다. 규칙은 맞추기 표본의 평균 energy로 고르고, 모든 비교는 평가 표본에서 합니다. 같은 표본으로 고르고 평가하면 자기 규칙이 과대평가되기 때문입니다.
- **모델 반복**: 규칙 하나와 표본 하나마다 모델 그래프를 3개 만들어 energy를 평균합니다(`--n-reps 3`). 모델 그래프가 하나면 시뮬레이션 잡음 때문에 같은 설정에서도 전이 지수가 크게 흔들렸습니다(4h절의 다섯 실행 비교). 위상 모델(`run_rule_transfer.py`)은 규칙당 모델 4개의 분포를 합쳐 비교합니다.

## 3. 무엇을 "전이"라고 부르나

원천 그래프 S에서 맞춘 규칙 θ̂_S를 바꾸지 않고 대상 그래프 G에 적용해, G를 얼마나 잘 재현하는지 봅니다. 매개변수 값을 직접 비교하지 않고 **재현 성능**으로 판정하는 이유는 세 가지입니다.

1. 매개변수끼리 서로 상쇄됩니다. 예를 들어 η를 조금 바꾸고 β를 조금 바꿔도 비슷한 그래프가 나올 수 있어서, 값이 달라도 같은 그래프를 만들 수 있습니다.
2. 매개변수마다 단위와 민감도가 달라, "η 0.25 차이"와 "β 0.25 차이"를 같은 무게로 볼 수 없습니다.
3. 우리가 묻는 것은 "선충의 규칙으로 초파리를 설명할 수 있는가"이고, 이는 재현 성능의 질문입니다.

매개변수 값(η, β)은 해석을 위해 따로 보고합니다.

## 4. 전이 지수

### 4.1 수식

```latex
TI(S \to G) \;=\; \frac{E_G(\theta_0) \;-\; E_G(\hat\theta_S)}{E_G(\theta_0) \;-\; E_G(\hat\theta_G)}
```

| 기호 | 뜻 |
| --- | --- |
| E_G(θ) | 규칙 θ로 만든 모델 그래프와 G의 **평가 표본** 사이 energy의 평균 (표본 8개 × 모델 반복) |
| θ₀ = (0, 0, 0) | 널 규칙: 같은 n, m의 ER 그래프 |
| θ̂_S | 원천 S의 **맞추기 표본**에서 energy가 가장 낮은 규칙 |
| θ̂_G | 대상 G 자신의 맞추기 표본에서 고른 규칙 |

읽는 법:
- **TI = 1**: S의 규칙이 G를 G 자신의 규칙만큼 잘 설명합니다.
- **TI = 0**: S의 규칙이 무작위 그래프보다 나을 게 없습니다.
- **TI < 0**: S의 규칙이 무작위 그래프보다도 나쁩니다(예: 허브를 과하게 만드는 규칙).
- **TI > 1**: 가능합니다. 평가 표본에서는 S의 규칙이 G의 규칙보다 우연히 나을 수 있습니다(G의 규칙도 맞추기 표본에서 골랐으므로). 1을 넘는 값은 "자기 규칙과 구별되지 않음"으로 읽습니다.

### 4.2 그룹 단위로 묶기

- 원천-대상 쌍을 종류별로 묶습니다: 같은 종 안(선충 개체끼리, 유충 좌우, 성체 좌우), 선충 → 유충, 유충 → 선충, 선충 → 성체 등.
- 종류마다 **쌍들의 중앙값**을 보고합니다. 선충은 8개체라 선충 → 유충 쌍만 16개이고, 한 개체의 이상값에 흔들리지 않도록 평균 대신 중앙값을 씁니다.

### 4.3 불확실성: 부트스트랩

규칙 선택 자체의 불확실성을 반영합니다.
1. 그래프마다 맞추기 표본 8개를 복원 추출로 다시 뽑습니다.
2. 다시 뽑은 표본으로 θ̂를 다시 고릅니다(원천과 대상 모두).
3. 평가 표본은 고정한 채 모든 쌍의 TI를 다시 계산하고, 종류별 중앙값을 냅니다.
4. 20번 반복해 중앙값들의 2.5~97.5% 범위를 95% 구간으로 보고합니다.

### 4.4 이 형태로 만든 근거

1. **"설명 가능한 이득 중 얼마를 회수했나"라는 정규화된 비율입니다.** 분자는 S의 규칙이 무작위보다 얼마나 나은지, 분모는 G 자신의 규칙이 무작위보다 얼마나 나은지입니다. 원시 energy는 대상마다 맞추기 어려운 정도가 달라서(예: 성체가 선충보다 무작위 energy가 높음) 그대로 비교할 수 없습니다. 비율로 바꾸면 대상의 난이도가 지워집니다.
2. **기상 예보 검증의 skill score와 같은 구조입니다.** SS = (S_기준 − S_예보) / (S_기준 − S_완벽)으로, 기준(기후값)보다 얼마나 나은지를 완벽한 예보 대비 비율로 나타냅니다(Murphy, 1988 `【확인 필요】`). 여기서 기준은 ER, 완벽은 대상 자신의 규칙입니다.
3. **이 저장소의 원래 전이 지수와 같은 사다리입니다.** `run_transfer.py`의 TI = (무척추동물 − 널) / (정답 − 널)과 같은 구조라, 프로젝트 전체에서 "전이"의 정의가 하나로 유지됩니다.
4. **널을 ER로 둔 이유**:
   - ER은 같은 모델 계열의 "모든 지수 = 0"인 특수한 경우라, 규칙이 있는 모델과 없는 모델이 한 계열 안에서 비교됩니다(중첩 모델).
   - 차수 보존 널은 차수 분포를 이미 담고 있어 허브 정보가 분모에서 사라집니다. 성체와 작은 신경계의 차이가 바로 허브 형성(β)이므로, 그런 널은 우리가 보려는 차이를 지웁니다.
5. **상한을 대상 자신의 규칙으로, 그것도 평가 표본에서 잰 이유**: 대상 그래프를 우리 모델 계열로 설명할 수 있는 최선이 그 정도이기 때문입니다. 모델 계열 자체의 한계(자기 규칙도 energy 0.2~0.4가 남음)는 분자와 분모에 똑같이 들어가 비율에서 지워집니다. 평가 표본을 쓰는 것은 과적합을 막기 위해서입니다.
6. **같은 종 안 TI를 기준선으로 쓰는 이유**: TI = 1이 현실에서 얼마나 달성 가능한지는 데이터가 정합니다. 같은 종의 다른 개체나 반구 사이 TI(최종 실행 0.95~1.10)가 "같은 규칙"의 실제 수준이고, 종 간 TI는 이것과 비교해 판정합니다.

### 4.5 주의할 점

- 분모 E_G(θ₀) − E_G(θ̂_G)가 0에 가까우면 비율이 불안정해집니다. 최종 실행(4i절)에서는 0.16~0.31이라 문제가 없었습니다. 분모가 0 이하면 TI를 정의하지 않습니다(코드에서 NaN).
- 격자가 거칠면 원천과 대상이 같은 격자 칸을 골라 TI가 정확히 1이 됩니다(4e절의 선충 개체 간 1.00). 0.25 간격 격자로 줄였지만 완전히 없어지지는 않습니다.
- TI는 우리 모델 계열 안에서의 전이입니다. 모델이 못 잡는 성질(세포 유형별 연결 규칙 등)의 전이는 말하지 않습니다.
