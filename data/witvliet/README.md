# *C. elegans* brain connectomes across development (Witvliet et al. 2021)

Nothing here is committed except this README. `sctransfer/witvliet.py` reads the eight
spreadsheets `raw/witvliet_2020_<k> <stage>.xlsx` (gitignored, about 300 KB), downloaded from the
OpenWorm ConnectomeToolbox repository (MIT), which mirrors the files hosted on WormWiring:
<https://github.com/openworm/ConnectomeToolbox/tree/main/cect/data>

- **Cite**: Witvliet, D. et al. (2021). Connectomes across development reveal principles of brain
  maturation. *Nature* 596, 257–261. doi:10.1038/s41586-021-03778-8
- Datasets 1–4: L1, 5: L2, 6: L3, 7–8: adult. Nerve-ring (brain) reconstructions of isogenic
  animals, 187–221 neurons with chemical synapses.
